# Лабораторная работа № 5. Визуальное программирование

Вариант 2, средний уровень. Одно приложение Tkinter объединяет три задания:

- № 2 — текстовое поле и кнопка, выводящая введённый текст;
- № 4 — список `Listbox` и вывод выбранного элемента;
- № 7 — меню `File → Exit`.

```bash
python -m lab05.app
```

После запуска введите текст и нажмите «Вывести». Для выбора элемента щёлкните
по нему в списке. Пункт `File → Exit` закрывает приложение.
