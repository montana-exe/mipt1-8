# Лабораторные работы 1–8 по МИТП

Решения выполнены по методическим указаниям для варианта 2. В лабораторной
работе № 1 выполнены все десять заданий среднего уровня. В лабораторных
работах № 2–8 выполнены задания среднего уровня № 2, № 4 и № 7.

## Состав проекта

| Работа | Тема | Выполненные задания |
|---|---|---|
| 1 | Система контроля версий Git | все задания 1–10 среднего уровня |
| 2 | Структурное программирование | 2, 4, 7 |
| 3 | Объектно-ориентированное программирование | 2, 4, 7 |
| 4 | Функциональное программирование | 2, 4, 7 |
| 5 | Визуальное программирование | 2, 4, 7 |
| 6 | Веб-программирование | 2, 4, 7 |
| 7 | Работа с СУБД | 2, 4, 7 |
| 8 | Экосистема Python | 2, 4, 7 |

Подробные условия, команды запуска и примеры находятся в `README.md` каждой
лабораторной работы.

## Установка и проверка

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m pytest
```

Все консольные демонстрации можно запустить одной командой:

```bash
python run_all.py
```

GUI лабораторной № 5 и веб-серверы лабораторной № 6 запускаются отдельно —
инструкции приведены в соответствующих каталогах.
