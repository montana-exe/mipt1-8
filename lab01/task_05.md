# Задание № 5. Ветка feature и новый файл

```bash
git switch -c feature
git add lab01/feature.py
git commit -m "feat(lab1): add feature module"
```

`git switch -c feature` одновременно создаёт ветку `feature` и переключается
на неё. В этой ветке был создан новый файл `feature.py`. Следующие две команды
добавили его в коммит `6d25f9c`.
