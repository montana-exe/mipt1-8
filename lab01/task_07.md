# Задание № 7. Файл .gitignore

В корне проекта создан `.gitignore`. Его основные строки:

```text
__pycache__/
*.py[cod]
.venv/
.env
*.db
```

`__pycache__/` исключает кэш Python, `*.py[cod]` — скомпилированные файлы,
`.venv/` — виртуальное окружение, `.env` — локальные переменные и секреты,
`*.db` — создаваемые примерами базы данных. Эти файлы не должны попадать в
учебный репозиторий.
