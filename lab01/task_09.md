# Задание № 9. Отправка изменений на GitHub

```bash
git push -u origin main
git push -u origin feature
```

`git push` отправляет локальные коммиты в GitHub. `origin` — имя удалённого
репозитория, а `main` или `feature` — отправляемая ветка. Параметр `-u`
запоминает связь веток, поэтому в дальнейшем достаточно команды `git push`.
