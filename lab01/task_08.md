# Задание № 8. Связь с GitHub

Удалённый репозиторий добавляется командой:

```bash
git remote add origin https://github.com/montana-exe/mipt1-8.git
git remote -v
```

`remote add` сохраняет адрес под коротким именем `origin`. `remote -v`
показывает адреса для получения и отправки изменений. В проекте `origin`
указывает на репозиторий `montana-exe/mipt1-8`.
