# Задание № 3. Добавление файла и первый коммит

Для задания был создан файл `main.py`, после чего выполнены команды:

```bash
git add lab01/main.py
git commit -m "feat(lab1): create Python project"
```

`git add` помещает текущую версию файла в область подготовленных изменений.
`git commit` сохраняет подготовленные изменения в истории. Параметр `-m`
задаёт понятное сообщение коммита.

Коммит можно найти в истории по сокращённому идентификатору `2b8d032`.
