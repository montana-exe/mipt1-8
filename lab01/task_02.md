# Задание № 2. Создание локального репозитория

```bash
mkdir mipt1-8
cd mipt1-8
git init
```

`mkdir` создаёт папку проекта. `cd` переходит в неё. `git init` создаёт
скрытый каталог `.git`, где Git хранит историю, ветки и настройки проекта.

В данном проекте репозиторий был получен с GitHub командой `git clone`, которая
одновременно создаёт локальный репозиторий и настраивает удалённый `origin`.
